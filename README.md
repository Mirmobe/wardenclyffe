# Wardenclyffe

Interactive 3D physics laboratory for Nikola Tesla’s machines.

The spark-gap coil is a two-mesh series RLC circuit: Wheeler inductance, Medhurst and toroid capacitance, mutual inductance from complete elliptic integrals, and a quenched spark integrated with RK4. Other exhibits are the 1888 rotating-field motor, the 1913 boundary-layer turbine, a resonant inductive link, and the Schumann cavity set next to Wardenclyffe.

```bash
npm install
npm run dev
```

Nothing in this model is a plan for building a high-voltage coil.
